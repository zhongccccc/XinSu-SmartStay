# 芯宿 · 智控 — 酒店自助入住与客房智能终端

基于 **进迭时空 SpacemiT K1（RISC-V）** 的酒店自助入住一体机，配两块 RK2206 + OpenHarmony 终端板，
完成「身份核验 → 选房 → 支付 → 下发门锁凭证 → 开门 → 退房作废」的完整闭环。

## 系统组成

```
              ┌──────────────── 800×480 触摸屏 ────────────────┐
              │      Chromium kiosk（Wayland / labwc 全屏）      │
              └───────────────▲────────────────────────────────┘
                              │ HTTP / SSE
              ┌───────────────┴────────────────────────────────┐
              │   zhikong-backend（Python 标准库 + SQLite）      │
              └──▲─────────────▲─────────────▲─────────────▲───┘
                 │USB 串口      │USB 串口      │USB          │MIPI CSI
        ┌────────┴──────┐ ┌────┴─────────┐ ┌──┴────────┐ ┌──┴──────────┐
        │ 门锁板 RK2206 │ │ 家居板 RK2206 │ │ 读卡器    │ │ 摄像头      │
        │ 键盘/指纹/NFC │ │ 温湿度/光照   │ │ 二代证    │ │ 现场人脸    │
        │ OLED/电机     │ │ 燃气/人体/LCD │ │ 房卡 RFID │ │             │
        └───────────────┘ └───────────────┘ └───────────┘ └─────────────┘
```

| 部分 | 硬件 | 说明 |
|---|---|---|
| 一体机 | SpacemiT K1 MUSE Pi Pro + 800×480 DSI 触摸屏 | Chromium kiosk + Python 后端 |
| 门锁板 | 通晓 Smart_Lock（RK2206 + OpenHarmony） | 密码 / 指纹 / NFC 开门，板端鉴权，断网可用 |
| 家居板 | 通晓 TX-SMART-R（RK2206 + OpenHarmony） | 温湿度 / 光照 / 燃气 / 人体 + 灯与风扇 + LCD |
| 外设 | 二代证读卡器、USB RFID 读卡器、扫码枪、MIPI 摄像头 | |

```

    devices/        设备抽象：门锁板 / 家居板 / 读卡器 / 身份证 / 扫码 / 相机 / 人脸

```

## 快速开始

### 一体机

```bash
sudo cp -r app /opt/zhikong/
sudo cp systemd/zhikong-backend.service /etc/systemd/system/
sudo systemctl enable --now zhikong-backend
bash /opt/zhikong/tools/start_both.sh      # 启动界面（物理屏 + VNC）
```

### 终端板

两板都是 RK2206 + OpenHarmony，用 RKDevTool 烧录，**必须先「擦除 Flash」**：

| 行 | 文件 | 地址 |
|---|---|---|
| loader | `rk2206_db_loader.bin` | `0x00000000` |
| firmware | 门锁板 / 家居板镜像 | `0x00008000` |

烧完断电重启；擦除会清空门锁板凭证，需要重新入住或调用 `POST /api/lock/resync` 补发。

## 关键设计

- **开门鉴权在门锁板本地**：密码、指纹、卡号都在板端校验，一体机只负责下发凭证，断网仍可开门。
- **串口端口自动认领**：三路 CH340 插拔后端口号会漂移，后端开机按协议握手认领（应答 `zk` = 门锁板，`zh` = 家居板，其余为读卡器），运行期不再扫描。
- **板子离线就报错**：不允许静默降级为「模拟成功」。
- **人证合一**：读卡器取身份证芯片照，摄像头连拍 3 帧，本机完成检测 → 对齐 → 特征 → 判定。
