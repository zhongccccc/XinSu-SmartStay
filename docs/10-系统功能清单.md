## 二、一体机（K1）

### 入住流程
| 步骤 | 功能 | 状态 |
|---|---|---|
| ① 身份核验 | 身份证读卡器（miniSTREAK HID） | ✅ |
| ② 人脸比对 | IMX219 摄像头 + 抓拍 | ✅ |
| ③ 在线选房 | 12 间房，**已订房置灰 + 红角标**，不可选 | ✅ |
| ④ 扫码支付 | 扫码器 (USBScn) | ✅ |
| ⑤ 房卡 | 读卡器录入卡号 | ✅ |
| ⑥ 凭证下发 | 房间号 + 开门码 + 房卡 + 有效期写入门锁板 | ✅ |
| ⑦ 完成页 | 显示开门码、房卡号、门锁状态 | ✅ |

### 完成页按钮
- **完成并返回** → 回待机，**保留**门锁凭证
- **门锁键盘（演示）** → 屏幕 PIN 面板，板端校验开门
- **退房（作废凭证）** → 作废该房间凭证并关单

### 待机页
- **退房 / 作废开门凭证**：列出所有在住房间，点选即作废该房间凭证
- 语音播报、实时事件提示（开锁/上锁/指纹/刷卡/按键）

### 后台能力
- SQLite 订单 / 审计 / 工单
- SSE 实时推送
- 串口自动发现门锁板（换号不用改配置）
- `/api/reset`（保留凭证）、`/api/checkout`（按房间作废）、`/api/lock/code`（板端校验）

## 三、智能门锁板（固件 v58）

### 开门方式（四种，全部实测）
| 方式 | 触发 | 鉴权位置 |
|---|---|---|
| **键盘密码** | 板载 TTP229 键盘，6 位 + `#`，`*` 退格 | **门锁板本地** |
| **指纹** | 板载指纹模块，按下即开 | **门锁板本地** |
| **板载 NFC 刷卡** | 首次刷卡自动绑定为房卡，之后直接开 | **门锁板本地** |
| 远程指令 | 一体机/接口 `zk open` | 系统 |

### 门锁动作
- 开锁 **400ms** / 关锁 **600ms**（阻塞式驱动，通足才断电）
- 开锁后 **6 秒自动上锁**
- 按键蜂鸣 **80ms**，开关锁提示音 140ms

### 显示（OLED 128×64）
- 锁图标（开/合两种）
- 6 个圆点遮罩显示已输入位数（不显示真实数字）
- 底部进度条

### 安全与管理
- 凭证本地校验，**断网可用**
- **按房间作废**（退房只影响该房间）
- 事件上报：开/上锁、按键、指纹 ID、刷卡、拒绝原因
- 调试命令：`zk ping / issue / open / lock / code / revoke / pt / gpio / oled / nfc / en1 / en2 / fpid / learn`

## 四、智能家居板（固件 v17）

### LCD 仪表盘（320×240 深色主题）
```
┌──────────────────────────────────┐
│ 芯宿智控              SMART HOME │
├──────────────────────────────────┤
│ 室内温度      28.8 C             │
│               湿度 57.6 %        │
│               光照 112 lx        │
├───────────┬──────────┬───────────┤
│ 人体感应   │  燃气    │  灯光     │
│  有人      │  正常    │  已开     │
└───────────┴──────────┴───────────┘
```
- 主指标式布局（温度占主视觉）
- **人体状态整格高亮**：有人=暗红底白字，无人=灰底灰字
- 局部刷新，无闪烁

### 传感器
| 传感器 | 接口 | 实测 |
|---|---|---|
| SHT30 温湿度 | I2C0_M2 @0x44 | ✅ 28.8°C / 57.6% |
| BH1750 光照 | I2C0_M2 @0x23 | ✅ 112 lx |
| 人体感应 PIR | GPIO0_PA3 | ✅ 正常触发 |
| 燃气 MQ-2 | ADC 通道 4 | ✅ 原始值 113 |

### 执行器
| 执行器 | 控制 | 说明 |
|---|---|---|
| **RGB 灯** | `zh light on/off` | 纯白光，占空比 1~99 |
| **风扇（电机）** | `zh fan on/off/N` | PWM 调速 1~99 |
| **蜂鸣器** | `zh beep 200` | 可做提示音 |

### 板载按键（ADC 分压）
| 按键 | 电压 | 功能 |
|---|---|---|
| **K3** | 0.01V | 一键全关（灯+风扇） |
| **K4** | 1.0V | 开关风扇（60%） |
| **K5** | 1.65V | 风扇调速循环：关→30→60→99→关 |
| **K6** | 0.55V | 开关灯 |

### 自动联动
- **有人 → 亮灯**（白光），**无人 5 秒后自动关灯**（测试值，正式可改 30~60 秒）
- 燃气超阈值（>2500）→ 报警标志

## 五、已验证的完整业务链

```
① 一体机办入住 → 凭证写入门锁板
② 门口输密码 / 按指纹 / 刷房卡 → 开锁 → 6 秒自动上锁
③ 退房 → 该房间凭证作废 → 旧码/旧卡被拒（其他房间不受影响）
```

实测记录：
- 键盘输码 → `CODE: ok` → `DOOR: open|keypad` → `close|auto`
- 指纹 → `FP: 0` → `DOOR: open|fingerprint`
- 刷卡 → `CARDBIND` → `DOOR: open|card`
- 退房 → 旧码 `{"ok": false}`，其他房间仍 `{"ok": true}`

## 六、已知限制 / 待办

| 项目 | 说明 |
|---|---|
| 家居板与一体机未联通 | 数据只在板载 LCD 显示，尚未上报到 K1 |
| 门锁板键盘 `2` 键 | 读数不稳，生成码已避开数字 2 |
| 门锁板 OLED | 无字库，只能画图形和圆点 |
| 家居板烧录 | **必须先"擦除 Flash"**，否则残留分区导致 boot loop |
| 燃气阈值 | 固定 2500，未做标定 |
| 风扇/灯的一体机控制 | 目前只能命令行 `zh fan/light` 或板载按键 |
