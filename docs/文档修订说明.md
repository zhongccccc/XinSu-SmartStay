## 二、新增的内容

1. **人脸比对（人证合一）**独立成章
   - 算法链路：YuNet 检测 → 5 点相似变换对齐 → ArcFace MobileFaceNet 特征 → 余弦相似度 + 双阈值
   - 四个关键实现要点（对齐必要性、L2 归一化、检测与关键点分开取、质量门控）
   - 离线实测数据（x86）：单帧约 31ms、正脸同人 0.89、阈值 0.45/0.32
   - **诚实标注状态**：算法与工程已完成离线验证；K1 真机标定与流程接入未完成，当前为模拟放行
   - 已知短板：MobileFaceNet 在暗光逆光下出现同人/异人分数倒挂，建议改 R50

2. **开发实录**（17 项真实故障的「现象 → 根因 → 改法」）
   - 模拟门锁静默降级、串口互抢、凭证槽占满、摄像头 ISP 超时致重启等

3. **真实部署细节**
   - 烧录必须先擦除 Flash；烧完必须重新下发凭证
   - 端口自动认领的协议与约束
   - 常用运维命令与排障手册

## 四、第二轮核对：逐项对照源代码

按「不能虚构没有做好的、用了什么技术就写什么」的原则，又把文档里的每个硬件参数回到代码里核对了一遍：

| 文档中的表述 | 核对结果 | 处理 |
|---|---|---|
| 开锁 400ms / 上锁 600ms / 6 秒自动上锁 | ✅ `zk_lock.c`：`g_open_ms=400`、`g_lock_ms=600`、`AUTO_LOCK_MS=6000` | 保留 |
| 凭证 8 槽 | ✅ `ZK_CODE_MAX = 8` | 保留 |
| OLED SSD1306 / I2C1 / 0x3C | ✅ 固件注释与初始化一致 | 保留 |
| 键盘 TTP229 / PA0 PA1 | ✅ 固件注释一致 | 保留 |
| 指纹接 UART2 | ⚠️ 注释写 UART2，代码是 `UART_FP 1`，两者不一致 | 改为「独立 UART」，不写编号 |
| NFC SPI0 | ✅ `SPI_NFC = ESPI0_M1`，芯片注释为 WS1850S / RC522 | 保留并补上芯片型号 |
| 家居板 SHT30 / BH1750 | ✅ `ADDR_SHT30 0x44`、`ADDR_BH1750 0x23` | 保留并补上地址 |
| 心跳「每 10 秒」 | ⚠️ 代码是每 20 次采样打印一次，10 秒是根据日志实测 | 改为「每 20 次采样打印，实测约 10 秒一次」 |
| 燃气阈值 2500 | ✅ 后端 `main.py`：`gas > 2500` | 保留 |
| 摄像头 IMX219 | ⚠️ 只有代码注释提到 IMX219，未核对实物模组 | 改为「MIPI 摄像头（spacemitsrc 管线）」 |
| 「断网可用」 | ⚠️ 架构上成立（鉴权在板端），但未做正式断网演练 | 改为「未做正式断网演练，仅确认无外网调用」 |
| 管理员强制退房「通过」 | ⚠️ 界面已验证，强制退房走的是同一个接口 | 改为「界面已验证；强制退房调用同一接口」 |

原则：**能在代码里找到出处的写具体数字，找不到出处的只写定性描述。**
